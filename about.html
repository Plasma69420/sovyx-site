About

Licensing for people who ship software.

Sovyx gives software sellers the server behind their product: keys, device locks, sessions, downloads and reseller access.

Why Sovyx exists

Sovyx started from the selling side of the software business: reselling, running fulfilment and answering buyers every day. It showed how much of that work comes down to the same few jobs: handing out keys, tying them to a device, knowing who is running what, and fixing it when someone changes PC.

The tools available were either general e-commerce platforms or a pile of scripts and spreadsheets that broke as soon as volume grew. So Sovyx was built to do just those jobs well, and to give every seller the same server behind their software that the big teams build for themselves.

How it's built

Sovyx is built and maintained in-house, and it is deliberately small.

Website

Hand-written HTML, CSS and JavaScript. No frameworks.

Server

A small Python service that handles sign-in, sessions, downloads and the Discord bot.

Data

Google Firebase stores accounts, keys and settings, with rules that keep each seller's data private.

Hosting

GitHub Pages for the site and Railway for the server.

What we care about.

Simple to add

One call to sign in, one to keep alive, one to sign out. If you can send an HTTP request, you can protect your software.

You stay in control

Ban a key, reset a device lock or end a session in a click, and the running program finds out within seconds.

Fair from the start

The Free plan is real: one application, 25 licenses, a customer page and HWID locks. Pay when you grow.
