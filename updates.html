Sovyx is live.

Today we're opening Sovyx to the public. Everything you need to buy, sell, and automate digital goods — the REST API, reseller panel, Discord bot, webhooks, and all four pricing tiers — ships today in v1.0.

Built for resellers, available to everyone. From single orders to high-volume automation — the same API, the same delivery speed, the same uptime across every plan.
REST API
Full v1 from day one
Orders, stock, keys, account endpoints — all stable, all documented, no beta disclaimers.
Reseller panel
Your brand, your buyers
Create a panel under your name. Set credit limits, issue keys, track everything.
Discord bot
Slash commands → DM delivery
Buyers order inside your server. Keys arrive as an ephemeral DM, invisible to everyone else.
Webhooks
Events land on your server
HMAC-signed payloads, 5 automatic retries, and order.fulfilled / stock.low events out of the box.
Shipping in v1.0
NewREST API v1 — /v1/orders, /v1/stock, /v1/keys, /v1/account and /v1/webhooks endpoints, all stable.
NewDiscord Bot — slash command ordering, ephemeral key delivery, and stock checks inside any server.
NewReseller panel — credit management, per-buyer limits, bulk key generation, and usage analytics.
NewFree, Pro, Ultra, and Elite plans. All four tiers live from day one — no waitlist, no invite codes.
NewWebhook signing with HMAC-SHA256. Every payload is signed; verification code is in the docs.
NewLicense key table — search, filter by status, bulk extend, and export across your entire key inventory.
NewAnnual billing across all plans. 20% off when you pay yearly.
New99.9% uptime SLA, enforced across all infrastructure. Status page at status.sovyx.cc.
